## 🎯 学习路径（循序渐进）

> **核心原则**：你按编号 L01→L20 **顺序阅读**，每节都以前面内容为基础。

### 卷一：内核基础（L01-L06）— 先懂得内核是什么
L01（内核模块）→ L02（设备模型）→ L03（PCI 驱动框架，**全篇关键骨架**）→ L04（PCI 枚举，硬件怎么发现设备）→ L05（桥拓扑）→ L06（并发同步，驱动里的锁）

### 卷二：PCIe 核心（L07-L10）— 资源怎么暴露
L07（配置空间读取）→ L08（BAR 地址映射）→ L09（内核资源树管理）→ L10（MMIO 映射到 CPU 地址空间，**GPU 验证的最关键入口**）

### 卷三：DMA 与 IOMMU（L11-L15）— 数据怎么搬
L11（PCIe 事务排序规则）→ L12（DMA 基础原理）→ L13（DMA API 实操）→ L14（Scatter-Gather 引擎）→ L15（IOMMU/VT-d 保护，**GPU 直通的关键技术**）

### 卷四：中断（L16-L18）— 硬件怎么通知 CPU
L16（MSI/MSI-X 原理）→ L17（Linux 中断框架，request_irq 完整路径）→ L18（中断下半部，workqueue 与 tasklet）

### 卷五：用户态交互（L19-L20）— 驱动写完怎么跟 app 通信
L19（字符设备接口）→ L20（mmap/ioctl/sysfs，三剑客）
